# Support

## Installation and usage help

Start with the [README](README.md), including its installation, configuration,
controls, and troubleshooting sections. Check existing issues before opening a
new one.

If the problem is reproducible, use the bug report form and include ESPHome and
Home Assistant versions, hardware revision, reproduction steps, and redacted
logs. Use the feature request form for proposed enhancements.

## Project scope

The provided configuration is written and tested for EchoEar v1.1. Ports to
other ESP32 devices with suitable displays are welcome, but device-specific
pinouts, memory limits, touch hardware, and display drivers may require
community support.

The project depends on Home Assistant, ESPHome, adsb.fi, ADSBDB, FlightAware,
and OpenStreetMap data. The maintainer cannot resolve outages, account problems,
rate limits, or data inaccuracies originating with those services.

Support is provided on a best-effort basis and immediate responses are not
guaranteed.

## Privacy and security

Redact credentials, API keys, exact home coordinates, access tokens, private
URLs, and personal data before sharing diagnostics. Follow
[SECURITY.md](.github/SECURITY.md) for vulnerabilities rather than posting them
in a public support issue.
