## OpenStreetMap

The bundled map, generated maps, and README map screenshot use data from
[OpenStreetMap](https://www.openstreetmap.org/copyright) contributors. The map
generator retrieves that data through the Overpass API. OpenStreetMap data is
available under the Open Data Commons Open Database License (ODbL).

- Live aircraft positions: [adsb.fi](https://opendata.adsb.fi/)
- Aircraft and route enrichment: [ADSBDB](https://www.adsbdb.com/)
- Optional authoritative flight times: [FlightAware AeroAPI](https://www.flightaware.com/aeroapi/)

Use of these services is subject to each provider's terms, availability, rate
limits, and pricing.
